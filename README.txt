MA FACTURATION — VERSION SIMPLE

1. Décompresse le dossier.
2. Ouvre index.html avec Chrome, Edge ou Firefox.
3. L'application fonctionne sans serveur et sans base de données.
4. Les données sont enregistrées dans le navigateur.
5. Dans Entreprise, renseigne tes informations.
6. Ajoute un client puis crée une facture.
7. Sur une facture, clique Imprimer / PDF pour enregistrer le PDF.

IMPORTANT :
- Cette version est volontairement simple et locale.
- Fais régulièrement "Exporter mes données".
- Pour un usage professionnel multi-utilisateurs, sauvegarde centralisée,
  authentification et facturation électronique, une version serveur sera nécessaire.
